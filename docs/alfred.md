# Alfred

## Install

Double-click `alfred/Desk Lock.alfredworkflow`. Alfred asks to import it, or to update it if an older version is installed. If your Alfred preferences sync between Macs, import it once.

The workflow contains no secrets. It calls `~/.local/bin/desklock`, which reads that Mac's token.

## Commands

| Type | Shows | Steps |
|---|---|---|
| `sleep all` | **Sleep on All Computers** | 1: runs on Enter |
| `screensaver all` | **Screensaver on All Computers** | 1: runs on Enter |
| `away` | **Lock all Macs**, then a choice of Sleep or Screen saver | 2 |

Typing just `sleep` or `screensaver` also shows macOS's own Sleep and Screen Saver commands. Pressing Enter on macOS's Sleep puts only this Mac to sleep. Pick the "on All Computers" item a few times and Alfred learns to list it first.

If `desklock` isn't installed or set up on the Mac, every command still locks that Mac and shows a notification saying the others weren't reached.

## Customizing

Edit keywords directly in Alfred Preferences → Workflows → Desk Lock. To lock with a key combination, add a Hotkey trigger (right-click the canvas → Triggers → Hotkey) and connect it to the "sleep" or "screensaver" Run Script action.

Changes made in Alfred are lost if you re-import the workflow from the repo. To make them permanent, change the source instead.

## Rebuilding the workflow

The `.alfredworkflow` file is generated by `alfred/build.py`. To change keywords or titles:

1. Edit the constants at the top of `alfred/build.py` (`AWAY_KEYWORD`, `SLEEP_KEYWORD`, `SAVER_KEYWORD`) or the titles in the `objects` list.
2. Run:

   ```bash
   python3 alfred/build.py
   ```

3. Double-click the new `alfred/Desk Lock.alfredworkflow` to update Alfred.
4. Commit both `build.py` and the `.alfredworkflow` file.

The workflow objects have fixed IDs, so re-importing replaces the existing workflow instead of adding a duplicate.

## How it's built

```
Script Filter "away" ──▶ Run Script: desklock "$1"        ($1 = sleep | screensaver)
Keyword "sleep all computers" ──▶ Run Script: desklock sleep
Keyword "screensaver all computers" ──▶ Run Script: desklock screensaver
```

Each Run Script action falls back to locking only the current Mac when `~/.local/bin/desklock` doesn't exist.
